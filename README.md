## Estrutura

As HQs atuais estão em PDF. Cada PDF possui uma capa WebP gerada automaticamente a partir da primeira página e cadastrada no `catalogo.json`.

O GitHub Pages publica apenas o índice e o catálogo. PDFs e capas são carregados diretamente pelo `raw.githubusercontent.com`.

A automação de capas também reconstrói o catálogo a partir dos PDFs presentes no repositório, para que novos uploads não fiquem fora da biblioteca.
