## Estrutura

As HQs estão em PDF, organizadas por coleção. Cada PDF possui uma capa WebP gerada automaticamente a partir da primeira página e cadastrada no `catalogo.json`.

O GitHub Pages publica o índice e o catálogo. PDFs e capas são carregados diretamente pelo `raw.githubusercontent.com`.

A automação de capas reconstrói o catálogo a partir dos PDFs presentes nas pastas do repositório, para que novos uploads compatíveis com o padrão não fiquem fora da biblioteca.
